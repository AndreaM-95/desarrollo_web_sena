¿Qué es la arquitectura de software?

La arquitectura de software define cómo se organizan los componentes de una aplicación, cómo se comunican y cómo se mantienen escalables y mantenibles.

Escalabilidad

Permite que el sistema soporte más usuarios sin romperse.

Mantenibilidad

El código debe ser fácil de modificar y entender.

Seguridad

Protege la información y controla accesos.

Principios de programación

DRY

No repitas código. Reutiliza lógica mediante funciones o clases.

KISS

Mantén el código simple. Un código sencillo es más fácil de mantener.

SOLID

Conjunto de principios para crear software limpio y flexible.

YAGNI

No implementes funcionalidades que aún no necesitas.

Principios de ingeniería de software

Análisis

Comprender el problema antes de programar.

Diseño

Planear estructura, base de datos y arquitectura.

Pruebas

Validar que el sistema funcione correctamente.

Mantenimiento

Actualizar y corregir errores del software.

¿Qué es un algoritmo?

Un algoritmo es una secuencia ordenada de pasos para resolver un problema.

Búsqueda

Encontrar datos dentro de una colección.

Ordenamiento

Organizar datos de menor a mayor.

Recursivos

Funciones que se llaman a sí mismas.
